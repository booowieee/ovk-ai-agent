# OpenVK AI Agent

Бот-автоответчик для социальной сети OpenVK на базе модели Google Gemini.

## Возможности
- Автоматически отвечает на упоминания в постах и комментариях.
- Фильтрует повторные запросы с помощью базы данных Redis.
- Поддерживает управление через Telegram-бота (включение, выключение, смена промпта, мониторинг статуса).
- Находит оригинальные посты для комментариев с упоминаниями, обходя ограничения OpenVK API.

## Установка и запуск

1. Сделайте копию файла настроек:
   ```bash
   cp .env.example .env
   ```

2. Заполните данные в файле `.env`:
   - `BOT_TOKEN` - токен Telegram-бота для управления.
   - `ADMIN_TELEGRAM_ID` - ваш числовой ID в Telegram для доступа к управлению.
   - `GEMINI_API_KEY` - ключ API Google Gemini.
   - `OVK_INSTANCE_URL` - адрес инстанса OpenVK (например, https://openvk.org).
   - `OVK_ACCESS_TOKEN` - токен доступа OpenVK.
   - `OVK_USER_ID` - ID вашего профиля в OpenVK.

3. Запустите проект через Docker Compose:
   ```bash
   docker compose up -d --build
   ```

## Как получить токен OpenVK (OVK_ACCESS_TOKEN)
1. Откройте веб-версию OpenVK в браузере.
2. Перейдите по ссылке авторизации приложения (замените `client_id` при необходимости):
   `https://oauth.vk.com/authorize?client_id=2685111&redirect_uri=https://oauth.vk.com/blank.html&response_type=token&scope=wall,notifications,offline`
3. После авторизации вас перенаправит на пустую страницу. Скопируйте значение параметра `access_token` из адресной строки браузера.

## Управление через Telegram
После запуска напишите вашему Telegram-боту команду `/start`. Доступные функции:
- Включение и отключение автоответчика.
- Просмотр текущих настроек подключения.
- Изменение системного промпта в реальном времени.
- Аварийная остановка (полная пауза обработки запросов).
